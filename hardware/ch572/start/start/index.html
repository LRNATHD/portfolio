    Getting Started with the CH572

    Foreword

    According to the datasheet, the CH572 was made "for 2.4G wireless communication applications and simple Bluetooth applications with low pin count" This is a vast understatement, as this is one of the most cost effective chips ever.

    Features

    The CH572 features 256kb of flash and 12kb of ram, bluetooth and 2.4ghz rf, I2C, SPI, PWM, GPIO,

    CH570 vs CH572

    The only difference is that the 72 support BLE 5.0. This is solely due to the code being allowed to run on it, if you are using the ch32fun library, there is NO DIFFERENCE between the 2 chips

    Design Guidelines

    Im (currently (2025) ) a high schooler with no formal pcb training outside of a real love of it and a want to learn more. I loved designing boards for the esp, and I seriously hope that this becomes my job one day.

    That being said, the CH572D is a pretty easy chip to design for. WCH are masters of making cheap chips that don't rely heavily on external components. The basics for this chip are a clock, a 1.5k resistor, and decoupling capacitors on the power input.
