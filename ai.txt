RULES
====
1. This is a Vite vanilla JS SPA — no frameworks
2. Hash-based routing (#/path) — see src/router.js
3. All CSS uses custom properties from src/styles/global.css
4. Gallery is the centerpiece — see src/components/gallery.js
5. Markdown content lives in content/ with YAML front matter
6. Dark mode only (--color-bg: #0a0a0f)
7. Accent color: #00d4ff (cyan)
8. Deploy via GitHub Pages — CI builds dist/

COMMANDS
====
npm run dev        # start dev server
npm run build      # build to dist/
npm run preview    # preview production build

TEMPLATES
====
[vite_multipage_entry]
rollupOptions: {
  input: {
    main: resolve(__dirname, 'index.html'),
    highschoolfinal: resolve(__dirname, 'highschoolfinal/index.html'),
  }
}

TROUBLESHOOTING
====
SYMPTOM: Page /highschoolfinal returns 404 in production build
CAUSE: Missing from rollupOptions.input in vite.config.js
FIX: Add highschoolfinal entry to vite.config.js rollupOptions.input
