RULES
====
1. Dark mode only — bg #0a0a0f, surfaces #111118
2. Accent color: #00d4ff (cyan/electric blue)
3. Fonts: Inter (body), JetBrains Mono (mono) — loaded via Google Fonts in index.html
4. Use CSS custom properties for all design tokens
5. BEM naming convention: block__element--modifier
6. gallery.css is the largest stylesheet — premium quality required
7. Reduced-motion media query required on all animation
8. Mobile breakpoint: 768px

====

| global.css       | Design tokens, resets (not yet created) |
